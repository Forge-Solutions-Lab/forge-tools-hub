## มันคืออะไร?
การติดตั้งและเชื่อมต่อชุดเครื่องมือ AI เข้ากับ **Claude Code CLI** ผ่านโครงสร้างมาตรฐาน `.claude-plugin/plugin.json` และ `marketplace.json` ช่วยให้คำสั่งเฉพาะทางทำงานเสมือนเป็นคำสั่งในตัวของ Claude

## ใช้ทำอะไรได้บ้าง?
- **Plugin Manifests:** กำหนดชุด Skills และ Hooks ที่ Claude จะโหลดขึ้นมาทำงานโดยอัตโนมัติ
- **Strict Schema Validation:** ตรวจสอบความถูกต้องของ Manifests ก่อน Deploy ด้วย `claude plugin validate`
- **Zero-Friction Sharing:** แชร์ชุดเครื่องมือระหว่างเพื่อนร่วมทีมเพียงแค่ clone repo
