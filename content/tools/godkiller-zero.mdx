## มันคืออะไร?
**GODKiller Zero MCP** คือ Local Proof-Kernel และ Model Context Protocol (MCP) server ระดับสูงที่พัฒนาขึ้นเพื่อควบคุมการตัดสินใจ การประเมินหลักฐาน และความปลอดภัยในการรันโค้ดของ AI Agent ให้ทำงานบนพื้นฐานของไฟล์จริงบนดิสก์ (`Disk > Chat`) โดยไม่สมมุติข้อมูลเอง

## ใช้ทำอะไรได้บ้าง?
- **Task & Phase Enforcement:** กำกับดูแลการทำงานตาม Phase อย่างเคร่งครัด พร้อมตรวจสอบ Phase Boundary ก่อนข้ามขั้นตอน
- **Write-Guard Safety:** ตรวจสอบความปลอดภัยในการแก้ไขไฟล์ ป้องกันการทำลายโค้ดหรือการเขียนไฟล์ที่ไม่ปลอดภัย
- **Automated Verification:** ตรวจสอบความถูกต้องของแผนงาน โค้ด และการทำงานผ่าน `gk_verify` และ `gk_evidence`
- **Context & Memory Persistence:** บันทึก Memory และ State แบบ Local โดยรักษาความเป็นส่วนตัว 100%

## เครื่องมือสำคัญที่มีในตัว (Facade Actions)
- `gk_meta`: ตรวจสอบสถานะความพร้อมของเครื่องมือ และความถูกต้องของแผนงาน
- `gk_guard`: กำกับความปลอดภัยในการอ่าน-เขียนไฟล์
- `gk_verify`: ยืนยันผลการทำงานและข้อเท็จจริงตามเกณฑ์มาตรฐาน
- `gk_task` / `gk_phase`: จัดการสถานะขั้นตอนการทำงาน
