## ทำไมต้องมี Universal Engineering Skills?

ในการทำงานร่วมกันระหว่างวิศวกรและ AI Coding Assistants (เช่น Antigravity, Cursor, Claude Code) หากไม่มีมาตรฐานกลางที่ชัดเจน จะเกิดปัญหาความสับสนในระบบ:
- **Architecture Inconsistency:** โค้ดขาด Layered Architecture, ผสม Business Logic เข้ากับ Presentation หรือ Controller
- **Context Drift:** เมื่อเริ่ม Session ใหม่ AI ลืมบริบทและสถาปัตยกรรมเดิม ทำให้ต้องเริ่มอธิบายใหม่
- **Unsafe Deployments:** สั่งคำสั่ง Docker ที่เสี่ยงต่อการสูญหายของ Data Volume หรือไม่มี Health Check รับรอง

## วิธีนำไปติดตั้งในโปรเจกต์ใหม่ (Quick Integration)

### 1. วางไฟล์ลงในไดเรกทอรี `docs/standards`
ดาวน์โหลดไฟล์ `.zip` จากปุ่มด้านบน แล้วแตกไฟล์ไว้ในโปรเจกต์:
```bash
# สร้างไดเรกทอรีและแตกไฟล์
mkdir -p docs/standards
unzip forge-universal-engineering-skills.zip -d docs/standards/
```

### 2. กำหนดเป็น System Instruction ให้กับ AI Assistant
```bash
# สำหรับ Cursor IDE
cp docs/standards/01-CODE_STYLE.md .cursorrules

# สำหรับ Claude Code / Antigravity
cp docs/standards/01-CODE_STYLE.md CLAUDE.md
```
