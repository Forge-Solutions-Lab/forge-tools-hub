## มันคืออะไร?
ชุดมาตรฐาน **Universal Engineering Workflows** สำหรับทีม Forge Solutions Lab ที่รวบรวมเทคนิคสำคัญ 3 ประการ:
1. **Context Handoff:** การสรุป State และหลักฐานลงดิสก์เมื่อสลับ Session เพื่อป้องกัน Context Drift
2. **Two-Axis Code Review:** ตรวจโค้ดเทียบกับความต้องการ (Spec Match) และมาตรฐานความสะอาดของโค้ด (Clean Code)
3. **Reproducible Bug Bisection:** การตีกรอบและจำลองเงื่อนไขที่ทำให้เกิดบั๊กก่อนลงมือแก้ไข

## ใช้ทำอะไรได้บ้าง?
- ส่งต่องานระหว่าง AI Session หรือระหว่างทีมอย่างราบรื่น
- ตรวจทาน Pull Request ได้รวดเร็วและแม่นยำยิ่งขึ้น
- ป้องกันปัญหาบั๊กหลุดไปถึง Production
