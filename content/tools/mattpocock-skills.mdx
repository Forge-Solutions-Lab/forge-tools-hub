## มันคืออะไร?
ชุด AI Engineering & Productivity Skills ที่ออกแบบโดย Matt Pocock (ผู้สร้าง Total TypeScript) เพื่อเปลี่ยน AI จากการเป็นแค่ Text Generator ให้กลายเป็น Senior Engineer ที่ทำงานตามมาตรฐานระดับสากล ผ่านกระบวนการ `Grill -> Spec -> Tickets -> TDD -> Code Review`

## ใช้ทำอะไรได้บ้าง?
- **Grilling (`/grill-with-docs`):** สัมภาษณ์เจาะลึกเพื่อเคลียร์ Requirement ให้กระจ่างก่อนลงมือเขียนโค้ด
- **Architecture Modeling (`/domain-modeling`):** จัดทำ Glossary และ Architecture Decision Records (ADRs) เพื่อคุมทิศทางโปรเจกต์
- **Systematic Bug Diagnosis (`/diagnosing-bugs`):** สร้าง Feedback Loop ที่รัดกุมก่อนตั้งสมมติฐานและแก้บั๊ก
- **Test-Driven Implementation (`/implement` & `/tdd`):** เขียนการทดสอบและโค้ดทีละ Slice อย่างมีวินัย

## Flow การทำงานหลัก
1. **`/grill-with-docs`**: เค้น Requirement และบันทึก `CONTEXT.md`
2. **`/to-spec` & `/to-tickets`**: แปลงเป็นแผนงานและแตกเป็น Task ย่อย
3. **`/implement`**: พัฒนาด้วย TDD และตรวจสอบ Code Review ก่อน Commit
