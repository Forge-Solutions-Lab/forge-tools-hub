## มันคืออะไร?
ชุด Prompt Template และ Best Practices สำหรับ AI Pair Programming ที่ผ่านการทดสอบจริงในสภาพแวดล้อมการทำงานของทีม ช่วยลดอาการพูดเยอะแต่น้ำ และสั่งการให้ AI สร้าง Output ที่กระชับ ตรงตาม Functional Requirements ทันที

## ใช้ทำอะไรได้บ้าง?
- **Concise Instruction Enforcement:** สั่งการให้ AI ไม่ร่ายยาว ตอบเฉพาะประเด็นทางเทคนิคที่จำเป็น
- **Context-First Prompting:** จัดวาง Context ของ Framework และ Database ให้ AI ทราบก่อนรับคำสั่ง
- **Refactor without Breaking:** แนวทางการสั่ง Refactor โค้ดโดยรักษาระบบเดิมไว้ไม่ให้กระทบ Core Logic

<BeforeAfter>
  <Before>
    AI ตอบคำอธิบายยาว 5 ย่อหน้าก่อนจะให้โค้ดจริง 3 บรรทัด และมักเปลี่ยนตัวแปรที่ไม่เกี่ยวข้อง
  </Before>
  <After>
    AI ให้โค้ดและคำอธิบายจุดสำคัญสั้นๆ ชัดเจน รักษา Structure เดิมของโปรเจกต์ 100%
  </After>
</BeforeAfter>
