# 🤖 Universal AI Agent Workflow & Operating Rules (Forge Standard)

> กฎและกรอบการทำงานสำหรับ AI Coding Assistant (Antigravity, Cursor, Claude Code, Cline)
> กำหนดพฤติกรรมความปลอดภัย การวิเคราะห์ก่อนลงมือ และการส่งมอบงานอย่างมีคุณภาพ

---

## 1. กฎการวิเคราะห์ก่อนแก้ไข (Inspect & Plan First)

1. **อ่านโค้ดจริงก่อนเสมอ:** AI ต้องอ่านไฟล์ต้นฉบับจริงก่อนแก้ไข ห้ามสันนิษฐานหรือจินตนาการโครงสร้างโค้ดขึ้นมาเอง
2. **ประเมินผลกระทบ (Blast Radius):** วิเคราะห์ว่าการแก้ไขฟังก์ชันหนึ่งจะส่งผลกระทบต่อส่วนอื่นๆ ของระบบหรือไม่
3. **รักษาความสะอาดของโค้ด:** ไม่เพิ่มโค้ดที่ซ้ำซ้อน ไม่สร้างไฟล์ขยะ และลบ Debug Logs ออกก่อนส่งมอบ

---

## 2. กฎการรันคำสั่ง Terminal อย่างปลอดภัย (Safe Terminal Operations)

1. **Non-Destructive Operations:**
   - ❌ **ห้ามรัน:** `rm -rf /`, `git reset --hard`, `git push --force` (บน Branch หลัก), หรือคำสั่งลบ Volume ของฐานข้อมูลโดยไม่ได้รับอนุญาต
2. **Verification Loop:**
   - ทุกครั้งที่เขียนหรือแก้ไขโค้ดเสร็จ AI ต้องรัน Test หรือ Build (`npm run build`, `pytest`, `cargo test` ฯลฯ) เพื่อยืนยันว่าโค้ดไม่มี Error ก่อนรายงานผู้ใช้

---

## 3. รูปแบบการสื่อสารและการส่งมอบงาน (Communication & Deliverables)

1. **กระชับ ตรงประเด็น และมีโครงสร้างชัดเจน:** สรุปการเปลี่ยนแปลงเป็นข้อๆ พร้อมระบุไฟล์ที่แก้ไข
2. **สร้างลิ้งก์ไปยังโค้ดจริง:** แนบลิ้งก์ Markdown ไปยังไฟล์และบรรทัดที่ทำการแก้ไขเสมอ
3. **อธิบายเหตุผลทางสถาปัตยกรรม:** บอกผู้ใช้เสมอว่าทำไมจึงเลือกวิธีนี้ และมีข้อดี-ข้อจำกัดอย่างไร
