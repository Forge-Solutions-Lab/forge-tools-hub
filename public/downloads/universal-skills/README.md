# Forge Universal Engineering Skills Bundle

ชุดมาตรฐานทางวิศวกรรม, แนวปฏิบัติการเขียนโค้ด, การรีวิวโค้ด, คำสั่ง Docker, กฎการทำงานของ AI Agent, และ Template การส่งต่องาน (Handoff) สำหรับทีม **Forge Solutions Lab**

---

## สารบัญเอกสารภายใน Bundle:

1. **`01-CODE_STYLE.md`** — มาตรฐานการเขียนโค้ดและ Clean Architecture สากล
2. **`02-AI_CODE_REVIEW_WORKFLOW.md`** — กระบวนการตรวจทานโค้ด (Code Review) 2 แกนพร้อม Checklists
3. **`03-DOCKER_WORKFLOW_RULES.md`** — กฎการรัน Docker และคำสั่ง Deployment อัตโนมัติ
4. **`04-HANDOFF_PROTOCOL.md`** — Template การส่งต่องานข้าม Session แบบ Zero Context-Drift
5. **`05-ADR_GUIDELINES_AND_TEMPLATE.md`** — มาตรฐานการบันทึกการตัดสินใจสถาปัตยกรรม (ADR)
6. **`06-PRD_AND_SPEC_TEMPLATE.md`** — Template การเขียนข้อกำหนดและสเปกฟีเจอร์ (PRD & Spec)
7. **`07-AGENTS_WORKFLOW_RULES.md`** — กฎและกรอบการทำงานของ AI Coding Assistant
